# Mundo Pequenino - E-commerce de Roupas Infantis

## 📝 Descrição do Projeto

Este projeto consiste em um site de e-commerce para a loja de roupas infantis "Mundo Pequenino", desenvolvido como parte de um trabalho interdisciplinar no curso Técnico de Informática. A iniciativa surgiu de uma colaboração com a turma de Administração, onde nosso grupo competiu com outras equipes. O objetivo principal foi criar uma plataforma funcional e visualmente atraente para a venda de produtos infantis.

É importante ressaltar que a maior parte da estrutura e funcionalidades do site foi desenvolvida com o auxílio de Inteligência Artificial. Nós, como equipe, realizamos pequenas alterações, ajustes finos e a integração das imagens, focando em adaptar o projeto às necessidades específicas do trabalho e em aprimorar a experiência do usuário. Este projeto demonstra nossa capacidade de trabalhar com ferramentas modernas e integrar soluções de IA no desenvolvimento web.

## ✨ Funcionalidades Principais

O site "Mundo Pequenino" oferece as seguintes funcionalidades:

*   **Catálogo de Produtos**: Exibição de produtos organizados por categorias (meninos, meninas, unissex) com opções de filtro e ordenação.
*   **Carrinho de Compras**: Sistema funcional para adicionar, remover e visualizar itens, com cálculo automático do total e persistência dos dados via `localStorage`.
*   **Navegação Intuitiva**: Menu responsivo e links entre todas as páginas para uma experiência de usuário fluida.
*   **Página "Sobre Nós"**: Detalhes sobre a história e os valores da loja.
*   **Página de Contato**: Formulário para que os clientes possam entrar em contato, com simulação de envio de mensagem.
*   **Simulador de Perfil Social**: Uma página extra que simula um perfil de rede social (inspirado no Instagram), apresentando destaques e publicações da loja, adicionando um toque criativo ao projeto.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

*   **HTML5**: Para a estruturação semântica do conteúdo.
*   **CSS3**: Para estilização, incluindo o uso de variáveis CSS, Flexbox, Grid Layout, Media Queries para responsividade e diversas animações e transições.
*   **JavaScript ES6+**: Para a lógica interativa do site, manipulação do DOM, uso da `LocalStorage API` para o carrinho, `Event Listeners` e a `Intersection Observer API` para animações de scroll.
*   **Font Awesome 6.0**: Para a inclusão de ícones vetoriais.

## 🚀 Como Executar o Projeto Localmente

Para visualizar o site em seu ambiente local, siga os passos abaixo:

1.  **Clone o repositório**: Utilize o comando `git clone https://github.com/C-Garcia1/mundopequenino.git` para baixar os arquivos.
2.  **Navegue até a pasta do projeto**: `cd mundopequenino`
3.  **Abra o arquivo `index.html`**: Você pode simplesmente abrir o arquivo `index.html` em seu navegador web preferido. Alternativamente, para uma experiência mais completa (especialmente se houver requisições assíncronas, embora não seja o caso aqui), você pode usar um servidor local:
    ```bash
    # Usando Python 3
    python3 -m http.server 8000
    # Acesse no navegador: http://localhost:8000
    ```
